# نبض (Nabd) — متجر الجوالات

متجر جوالات تجريبي مبني بـ React + Vite + Bootstrap RTL.

## التشغيل محليًا

يتطلب [Node.js](https://nodejs.org) (نسخة 18 أو أحدث).

```bash
npm install
npm run dev
```

بعدها افتح الرابط اللي يظهر في الطرفية (عادة `http://localhost:5173`).

### أوامر أخرى

```bash
npm run build     # بناء نسخة الإنتاج في مجلد dist/
npm run preview   # معاينة نسخة الإنتاج محليًا
```

## هيكلة المشروع

```
src/
  main.jsx              نقطة الدخول
  App.jsx                المكوّن الجذر (التنقل والحالة العامة)
  index.css              كل الأنماط المخصصة
  data/products.js        بيانات المنتجات (4 أجهزة) والماركات والعملة
  components/             كل مكوّن واجهة في ملفه الخاص
public/images/             صور المنتجات (قابلة للاستبدال)
```

## تغيير صور الجوالات

كل منتج له صورة داخل `public/images/` — حاليًا صور توضيحية محايدة بدون أي شعار. لتغييرها بصورك الخاصة:

1. افتح مجلد `public/images/` من داخل VS Code.
2. استبدل أي ملف بصورتك، وسمّها **بنفس اسم الملف القديم بالضبط**.
3. أو غيّر قيمة `image` لنفس المنتج داخل `src/data/products.js` لمسار جديد.

**ملاحظة حقوق ملكية:** تجنب صور رسمية من مواقع الشركات أو صور محمية بحقوق نشر — استخدم صورك أو صور من مواقع مرخّصة (Unsplash، Pexels، Pixabay).

## ملاحظات مهمة

- هذا مشروع واجهة أمامية (frontend) فقط — تسجيل الدخول، الطلبات، والدفع كلها **محاكاة (mock)** تعمل بالذاكرة ولا تُخزَّن بشكل دائم.
- لمتجر حقيقي تحتاج خادم خلفي (backend)، قاعدة بيانات، وبوابة دفع معتمدة (مثل مدى/Tap/Moyasar).
- Bootstrap CSS وخطوط Google محمّلة عبر روابط CDN في `index.html`؛ تحتاج اتصال إنترنت عند التشغيل.
